# الكوخ • EL KOKH | Interactive 3D Restaurant Menu 🍔✨

> موقع منيو تفاعلي فاخر ثلاثي الأبعاد لمطعم وكافيه **"الكوخ | El Kokh"**، مستوحى من أحدث تقنيات الويب والتصوير الفوتوغرافي التجاري الراقي (Editorial Food Presentation).

---

## 🌟 المميزات الرئيسية (Key Features)

1. **تجربة بصرية تفاعلية ثلاثية الأبعاد (3D Exploded View)**:
   - عرض صور فوتوغرافية حقيقية عالية الجودة للأطباق المجمعة.
   - إمكانية تفكيك كل طبق إلى طبقاته ومكوناته الفيزيائية مع خطوط إرشادية أنيقة باللغتين العربية والإنجليزية.
   - إعادة التجميع السلس بنقرة واحدة.

2. **قائمة طعام حقيقية كاملة (13 قسماً و 97 صنفاً)**:
   - مستخرجة بالكامل من منيو مطعم "الكوخ" الرسمي المعتمد.
   - أسعار دقيقة بالجنيه المصري (LE).
   - معلومات طهي دقيقة: السعرات الحرارية، زمن التحضير، وتوصيات الشيف.

3. **سلة طلبات منبثقة تفاعلية (Cart Slide-Over Drawer)**:
   - إضافة سريعة للأصناف مع صورها الحقيقية.
   - أزرار زيادة ونقصان الكميات وحذف الأصناف.
   - حساب فوري للإجمالي بالجنيه المصري وتأكيد استلام الطلب.

4. **بحث فوري لحظي ثنائي اللغة (Bilingual Live Search)**:
   - بحث بالاسم العربي، الاسم الإنجليزي، القسم، أو المكونات.
   - الانتقال الفوري للطبق في الشاشة الرئيسية.

5. **دعم كامل للغتين (العربية RTL والإنجليزية LTR)**:
   - تبديل سلس ومرن للهوية البصرية والخطوط والاتجاهات.

6. **استوديو الذكاء الاصطناعي وإدارة الأصناف (AI Product Creator Studio)**:
   - مراجعة استيراد المنيو، تعديل الطبقات، وتوليد مكونات إضافية.

## 📂 بنية المشروع (Project Structure)

```
html.test/
├── assets/
│   ├── products/         # صور فوتوغرافية تجارية حقيقية للأطباق والمشروبات
│   └── pdf_extracted/    # صفحات وأصول مستخرجة من منيو الـ PDF
├── scripts/
│   ├── components/       # مكونات الواجهة (Hero, Navbar, Carousel, AdminStudio)
│   ├── core/             # المحركات الأساسية (AnimationEngine, Store, MediaManager, AIProductAnimator)
│   ├── data/             # قاعدة بيانات المنيو (demoMenu.js)
│   └── app.js            # نقطة الدخول الرئيسية
├── styles/
│   ├── theme.css         # متغيرات الألوان الفاخرة والخطوط
│   ├── main.css          # الأنماط العامة والهيدر وسلة الطلبات والكاروسيل
│   ├── exploded-view.css # أنماط العرض ثلاثي الأبعاد والطبقات المتفككة
│   └── admin.css         # أنماط لوحة تحكم الاستوديو
├── index.html            # الصفحة الرئيسية
└── README.md             # دليل المشروع
```

## 🚀 كيفية التشغيل محلياً (How to Run Locally)

يمكنك تشغيل المشروع باستخدام أي خادم ويب بسيط:

```bash
# باستخدام بايثون:
python -m http.server 3000

# أو باستخدام Node npx serve:
npx serve .
```

ثم افتح المتصفح على الرابط: `http://localhost:3000`
